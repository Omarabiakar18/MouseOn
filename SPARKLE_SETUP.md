# Sparkle OTA Updates — Setup Guide

## Status: Code Ready ✅ | Signing Required ⏳

Everything is prepared. Once you have an Apple Developer ID ($99/year), follow these steps:

### Step 1: Add Sparkle Package
In Xcode:
1. File → Add Package Dependencies
2. URL: `https://github.com/sparkle-project/Sparkle`
3. Version: 2.x (latest stable)
4. Add to MouseOn target

### Step 2: Add Info.plist Keys
Add these to your Info.plist (or in Xcode target settings):
```xml
<key>SUFeedURL</key>
<string>https://raw.githubusercontent.com/Omarabiakar18/MouseOn/main/appcast.xml</string>
```

### Step 3: Generate EdDSA Keys
```bash
# After adding Sparkle package, find the generate_keys tool:
find ~/Library/Developer/Xcode/DerivedData -name "generate_keys" -type f
# Run it:
./generate_keys
# Save the PRIVATE key securely
# Add the PUBLIC key to Info.plist as SUPublicEDKey
```

### Step 4: Code Sign & Notarize
```bash
# Build with Developer ID signing
xcodebuild -scheme MouseOn -configuration Release CODE_SIGN_IDENTITY="Developer ID Application: Your Name"

# Notarize
xcrun notarytool submit MouseOn.dmg --apple-id your@email.com --team-id TEAMID --password app-specific-password
```

### Step 5: Update appcast.xml
For each release, add an `<item>` to appcast.xml with:
- Version number
- Release notes
- DMG download URL (GitHub Releases)
- EdDSA signature (generated by Sparkle's `sign_update` tool)

### Step 6: "Check for Updates" Menu Item
SparkleManager.swift is already created. Add to your Settings view:
```swift
Button("Check for Updates…") {
    SparkleManager.shared.checkForUpdates()
}
.disabled(!SparkleManager.shared.canCheckForUpdates)
```
