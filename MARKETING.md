# MouseOn - Marketing Strategy

## 🎯 Target Audience

**Primary:**
- Mac users with multiple monitors
- Developers / designers with complex setups
- People using iPad as second screen (Sidecar/Universal Control)

**Secondary:**
- Productivity enthusiasts
- Remote workers with home office setups
- Streamers / content creators

---

## 🐦 X (Twitter) Launch Strategy

### Phase 1: Personal Story (Build Connection)

**Post 1 - Introduction**
```
Hey 👋 I'm Omar, a 23yo CS student from Lebanon

I work full-time as a dev, study, AND I'm building my first macOS app

It's called MouseOn - shows which monitor your cursor is on

Sounds simple but I lost my cursor 100x a day before this 😅

🧵 Here's the story...
```

**Post 2 - The Problem**
```
The problem:

I have my MacBook + external monitor + iPad via Sidecar

My cursor disappears ALL the time

"Where did it go??"
*shakes mouse aggressively*

Every. Single. Day.

So I built MouseOn 🖱️
```

**Post 3 - The Solution**
```
What MouseOn does:

✅ Shows display name in menu bar
✅ Press ⌥⌘F to highlight your cursor
✅ Works with Sidecar & Universal Control
✅ Custom names for each display (emojis work! 🖥️📱)
✅ Track time spent on each display

Built in Swift 🍎
```

**Post 4 - The Ask**
```
I'm a student trying to pay tuition

No VC funding, no App Store (can't afford $99/year)

Just me, late nights, and too much coffee ☕

If MouseOn helps you, consider supporting an indie dev

Link in bio 🙏

RT appreciated! 🔄
```

## 💰 Pricing Strategy

**Launch price:** $2.99 (low barrier, builds reviews)
**Regular price:** $4.99
**Why not free:** Signals quality, filters serious users

---

## 🎁 Launch Offer Ideas

1. "First 100 buyers get it for $2.99" (urgency)
2. "RT for a chance to win a free copy" (reach)
3. Student discount: $1.99 with .edu email

---

## 📅 Launch Timeline

**Week 1: Tease**
- Post about the problem (no product mention)
- Engage with similar posts
- Build anticipation

**Week 2: Reveal**
- Share the story thread
- Post demo video
- Announce launch date

**Week 3: Launch**
- Drop the link
- Ask for RTs
- Respond to every comment
- Post updates/testimonials

**Week 4+: Sustain**
- Share user feedback
- Post tips/tricks
- Add features based on requests

---

## 🧠 Psychological Hooks

1. **Underdog story**: Student from Lebanon, no big budget
2. **Relatable problem**: "You KNOW the frustration"
3. **Social proof**: "X people already using it"
4. **Scarcity**: "Launch price ends soon"
5. **Reciprocity**: "I'm sharing my journey, support if you can"

---

## 📊 Track These Metrics

- Impressions per post
- Engagement rate
- Link clicks
- Conversion rate
- Revenue

---

## 🚫 What NOT To Do

- Don't spam the same post
- Don't be desperate ("please buy" = cringe)
- Don't argue with critics
- Don't oversell - be genuine
- Don't ignore comments
